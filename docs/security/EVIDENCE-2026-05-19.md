## Remaining prioritized risks (post 2026-05-21 rollout)

1. **semver-pinned Actions backlog** — migrate `uses:` tags → commit SHAs (`github-actions-pinning.md`).
2. **`hasInstallScript` allowlist hygiene** — expanding native stack must update [`scripts/list-lifecycle-scripts.mjs`](../../scripts/list-lifecycle-scripts.mjs).
3. **`npm audit` / Dependency Review noise** — transitive high findings (electron/sqlite/tar/axios chain) require coordinated upgrades; expect failing PR checks until resolved.
4. **Helmet CSP `'unsafe-inline'`** — needs build-time nonce strategy (see **`CSP_AND_FRONTEND_NOTES.md`**).

See rolling hardening checklist: [`ai-code-security-checklist.md`](./ai-code-security-checklist.md).
